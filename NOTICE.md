# Upstream projects

This repository contains customized copies of the `quick-term` and `iterm2`
themes from [Oh My Posh](https://github.com/JanDeDobbeleer/oh-my-posh), distributed
under its MIT license. The original license is in `licenses/oh-my-posh.txt`.

Tools and plugins are downloaded from their official releases or source archives;
they are not vendored in this repository. They retain their upstream licenses.

- https://github.com/JanDeDobbeleer/oh-my-posh
- https://github.com/sharkdp/fd
- https://github.com/junegunn/fzf
- https://github.com/ajeetdsouza/zoxide
- https://github.com/sharkdp/bat
- https://github.com/sxyazi/yazi
- https://github.com/BurntSushi/ripgrep

- https://github.com/zsh-users/zsh-syntax-highlighting
- https://www.zsh.org
- https://github.com/tmux/tmux
- https://www.postgresql.org
- https://github.com/lsof-org/lsof

Linux base dependencies are obtained from the user's distribution repositories.
Their package licenses and notices remain part of those packages. The installer
does not redistribute the downloaded tool binaries in this Git repository.

Optional Yazi preview dependencies and font guidance follow
[Yazi's installation documentation](https://yazi-rs.github.io/docs/installation/)
and [Oh My Posh's font documentation](https://ohmyposh.dev/docs/installation/fonts).
